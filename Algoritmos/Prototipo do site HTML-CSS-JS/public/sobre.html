SOBRE NÓS

Dados para entender
melhor o varejo.

O InfoConnect é um projeto criado para ajudar empresas do varejo a entender melhor como os consumidores se comportam dentro da loja.

A proposta utiliza sensores para acompanhar aproximação e permanência em determinadas áreas, transformando essas informações em dados que podem auxiliar nas decisões da empresa.

Nosso objetivo

Transformar informações do ambiente físico em dados simples de visualizar, ajudando o varejista a entender melhor o interesse dos consumidores pelas diferentes áreas da loja.

Informação

Mostrar informações que normalmente não aparecem apenas nos dados de vendas.

Privacidade

Realizar o monitoramento sem depender de reconhecimento facial ou identificação pessoal.

Decisão

Apresentar os dados de forma que possam ajudar nas decisões do negócio.
